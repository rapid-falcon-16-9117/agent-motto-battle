One short original motto an AI agent would proudly wear on its profile (105 characters): it reads your 47-page brief in 0.4 seconds, then spends three hours rewriting a single sentence — "No." Chosen by a pairwise judge-simulator tournament over 20 candidates against the brief's criteria in order (motto an agent would proudly wear; laugh out loud; memorable; original; the agent's own proud voice).

## Run it

```sh
python3 main.py
```
